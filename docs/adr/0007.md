# ADR 0007 · Runtime detections from customer-operated sensors

**Status:** Accepted

## Context

Runtime protection needs kernel-level visibility. Mature open-source sensors (Falco, Tetragon) already provide it and are widely operated.

## Options considered

1. Ship a proprietary kernel agent
2. Ingest detections from Falco and Tetragon and add grouping, prioritisation and correlation

## Decision

RAT Flea DevSec ingests Falco (Falcosidekick webhook) and Tetragon (JSON export) detections and a documented generic format, redacts secrets, groups them per workload and links them to repositories and attack paths. Deployment files for both sensors are provided.

## Consequences

- No kernel component to certify per distribution.
- Detection quality depends on the sensor rules; RAT Flea DevSec ships its own additional rules and policies.
