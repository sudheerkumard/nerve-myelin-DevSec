# ADR 0006 · Attack paths require exposure, weakness and impact

**Status:** Accepted

## Context

Graph views that show every possible connection overwhelm teams. A path is useful only when it describes something an attacker could do now.

## Options considered

1. Report every reachable chain
2. Report a path only when one workload combines exposure, an exploitable weakness and privileged access or data

## Decision

A path is created only when all three conditions hold on one workload, and it is stored as a finding with every step as evidence.

## Consequences

- Paths are few, ranked first and closed automatically when any link breaks.
- Exposure is limited to what the collectors can see; analysts confirm paths that depend on controls outside the account.
