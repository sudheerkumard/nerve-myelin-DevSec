# ADR 0003 · Scans run in the customer's runner

**Status:** Accepted

## Context

Customers in regulated industries cannot send source code to a third party, and many run CI inside private networks.

## Options considered

1. Hosted scanning of uploaded code
2. Engines shipped as a CLI that runs in the customer's CI and uploads only results

## Decision

The engines run in the customer's runner through the myelin CLI (or the myelin-cli image). Only findings, the SBOM and metadata are uploaded. One-click repository scanning on the platform fetches a read-only snapshot, scans it and deletes it.

## Consequences

- No source code is retained by the platform.
- The same engine version gives the same results in CI, on a workstation and on the platform.
- Customers update the CLI with the platform; the version is recorded with every scan.
